# Mẫu được sinh từ code

Repository không chứa STL/OBJ scan. Dùng nút mẫu mô phỏng trong app hoặc chạy python build_demo.py --output demo_export. Hàm hand_demo_mesh trong cast_template.py sinh hình tổng hợp cẳng tay–cổ tay–bàn tay; demo_mesh trong geometry.py sinh ống cẳng tay. Không dùng dữ liệu người thật.
